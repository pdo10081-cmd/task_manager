Лабораторна робота №1 

1.Створює локальний хостинг, приймає запити від браузера, передає код файлу php інтерпретатору та відправляє результат у нашому випадку це виведення строки і сторінки.

2.Розширенння файлу .php код усередені позначається як <?php ?>.

3.При подвійному кліку файл відкривається напряму з диска, а браузер без інтерпритатора и apache не вміє виконувати код, тому він покаже текст у файлу .php Якщо ж відкрити файл у браузері за адресою localhoct при запущеному apache, у браузері виведе результат виконання коду.

4.За вивід данних строк чисел змінних у браузер наприклад echo "Hello, World!"; виведе Hello, World! на сторінці браузера.

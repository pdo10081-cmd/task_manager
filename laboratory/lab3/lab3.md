Лабораторна робота №3 (2 години)

1.Оператори порівняння: == рівність, != нерівність, < менше, > більше, 
<= менше або дорівнює, >= більше або дорівнює, === тотожність - однаковий тип і значення.

2.Наприклад, $a = 5 та $b = "5";
var_dump($a == $b);
Якщо порівнювати через ==, буде true, тому що рядок "5" приводиться до числа 5.

var_dump($a === $b);
Оператор === порівнює і тип, і значення: "5" це string, а 5 це int, тому буде false.

3.Для виводу значень у нашому випадку або "Виконано", або "В процесі"
альтернативний синтаксис набагато зручніший для читання та написання, 
якщо порівнювати з фігурними дужками.

Ось як виглядає код з фігурними дужками:
<li>
    Завдання: <?= $taskTitle ?>
    <?php if ($isCompleted == true) { ?>
       ✔️ Виконано
    <?php } else { ?>
       🕒 В процесі
     <?php } ?>
</li>

На мою думку, писати такий код довше й заплутаніше.

4.$class = $isCompleted ? 'task-done' : 'task-pending';

Тернарний оператор — це спосіб скоротити конструкцію if-else в один рядок.

if ($isCompleted) {
    $class = 'task-done';
} else {
    $class = 'task-pending';
}

перетворюється на: $class = $isCompleted ? 'task-done' : 'task-pending';

Синтаксис: умова ? значення_якщо_істинно : значення_якщо_хибно

Використання є недоцільним, коли умови складні або вкладені одна в одну, 
або коли потрібно виконати кілька дій, а не просто повернути одне значення.

5.У if(...) до false приводяться: false, 0, 0.0, null, "0", "", [].
